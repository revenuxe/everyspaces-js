# SEO implementation audit — 14 November 2026

## Fixed

- Route-specific Open Graph and Twitter titles, descriptions, and images for marketing/service pages and kitchen layouts; Bangalore service aliases share their canonical page's metadata.
- FAQ JSON-LD now matches the homepage, service, services hub, and contact FAQ content. Accordion answers remain in server-rendered HTML. CMS FAQ blocks are rendered in article content.
- Removed the kitchen's inappropriate QAPage markup, the AI tool's invisible FAQ markup, and its unsupported aggregate rating.
- Structured data escapes HTML delimiters, uses the canonical www host, actual service image assets, absolute image URLs, and numeric price ranges instead of strings containing a range.
- Studio pages explicitly use noindex. Robots rules permit reading HTML noindex directives and consistently exclude API URLs for listed crawlers.
- CMS sitemap entries exclude noindex posts and posts canonicalized elsewhere, use actual modification dates, and deduplicate URLs.
- Added generated-HTML verification: `npm run build` then `npm run seo:check`.
